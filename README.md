# Android Event Management Application

## 1. Project Overview

EventHub is an Android application developed as part of the Mobile Application Development (MAD) project. It provides a user interface for exploring event-related information and browsing categories such as Music, Technology, Food, Weddings, and Sports.

The project focuses on organizing application screens through XML layouts and maintaining a consistent user interface.

## 3. Development Requirements

The following tools and components are required to open and run the project:

- Android Studio
- Android SDK components required by the project
- Gradle build system and project dependencies
- Android Emulator or a compatible Android device

An internet connection may be required during the initial Gradle synchronization to download dependencies.

## 4. Project Setup and Execution

Follow these steps to run the application on Linux:

1. Open Android Studio.
2. Select **Open** from the welcome screen or File menu.
3. Navigate to the project directory and select the root folder containing `settings.gradle.kts`.
4. Wait for Gradle Sync to complete.
5. Open **Tools → Device Manager** and start an Android Virtual Device, or connect a compatible Android device.
6. Select the application run configuration.
7. Click **Run** to build, install, and launch the application.

If Gradle Sync or the build fails, review the error messages in Android Studio before modifying the project configuration.

## 5. XML Layout Organization

The application's user interface is organized through Android XML layout and resource files.

The main resource locations include:

- `app/src/main/res/layout/` — XML files defining screen layouts and UI components.
- `app/src/main/res/drawable/` — drawable resources used by the interface.
- `app/src/main/res/values/` — resource values such as strings, colors, and themes.
- `app/src/main/AndroidManifest.xml` — application configuration and component declarations.

The available layout and resource files can be reviewed in Android Studio.
